## Deviations from plan

1. **`Microsoft.EntityFrameworkCore.Relational` 10.0.14 added to `Medilog.Infrastructure.csproj`.**
   Reason: `ToTable(...)` and all relational APIs were unavailable for compilation because the
   existing `Design` reference sets `IncludeAssets` without `compile`, which reduced Relational's
   compile asset to a `_._` placeholder. Approved by the Cycle owner during the session. No
   database provider is selected and Q-10 / D-01 remain open.
2. **Entity constructors initialise `CreatedAtUtc`.** Added during `review` to resolve finding #1;
   approved by the Cycle owner.
3. **`DiagnosisDate` renamed to `DiagnosisDateUtc`.** Added during `review` to resolve finding #2;
   approved by the Cycle owner.

## Remaining risks and blockers

1. **No migration.** The schema exists only as C# configuration. Until a provider is approved,
   nothing proves the model can be created against a real database.
2. **Audit interceptor not implemented.** `CreatedAtUtc` is set at object construction; without
   the F4-C2 interceptor, `UpdatedAtUtc` stays `null` and the created timestamp may not equal the
   actual insert time. No write path exists yet, so nothing is currently wrong in persisted data.
3. **No runtime verification of the EF model.** AC-2 and AC-3 are verified by inspection only.
4. **`dotnet-ef` tools are older (10.0.2) than the runtime (10.0.14).** Update before the first
   `migrations add`.
5. **`PatientId` duplication** between a visit and its children is not enforced by the schema;
   F4-C2 must reject mismatches.
