## 4. Design

### 4.1 Endpoints

| # | Method | Route (P-A) | Success | Ordering (P-C) |
|---|--------|-------------|---------|----------------|
| 1 | `GET` | `/api/patients/{patientId:guid}/notes?pageNumber=&pageSize=` | `200` `PagedResult<PatientNoteResponse>` | `CreatedAtUtc` desc, id tie-break |
| 2 | `GET` | `/api/patients/{patientId:guid}/lab-results?pageNumber=&pageSize=` | `200` `PagedResult<PatientLabResultResponse>` | `TestDate` desc, id tie-break |

`PatientNoteResponse(id, doctorId, doctorName, noteContent, createdAtUtc, updatedAtUtc)`
`PatientLabResultResponse(id, visitId?, testName, testDate, value, unit, referenceRange?, notes?)`
Both carry `visitId: null | Guid` (C-3). Doctor name resolved by the store projection.

### 4.2 Authorization order (identical to F3-C1/C2 — no new logic)

1. Role ≠ Doctor → `403 medical.access_denied` (before any store call).
2. Missing/empty user id → `403 identity.invalid`.
3. Validate request shape (shared `PagedQueryValidator<T>` + `PatientId` not empty).
4. Doctor missing/inactive → `403 identity.invalid`.
5. Patient unknown / `DoctorId` null / owned by another doctor → uniform `404 patient.not_found`.
6. Only then read, always keyed by the verified `patientId`.

### 4.3 Error contract

Same as F3-C2 (verified in `ApiProblem.FromStatusCode`): 401 `auth.unauthorized`,
403 `access.forbidden` (framework) with the Application `medical.access_denied` boundary behind
it, 404 `patient.not_found`, 400 `validation.failed` with camelCase `errors`/`errorCodes`.

## 6. Test plan (extends `MedicalRecordsApiTests` — per endpoint)

1. **Authorized doctor:** 200; all seeded records returned (linked + unlinked — C-2); `visitId` present and correct (C-3); `doctorName` populated for notes; ordering (P-C); paging envelope exact (Q-04).
2. **Omitted query:** defaults 1/10 from `PagingDefaults`.
3. **Beyond last page:** 200 with empty `items`, correct metadata.
4. **Secretary:** 403 with **zero medical data** in the body.
5. **Cross-doctor:** uniform `404 patient.not_found`, no data.
6. **Unauthenticated:** 401, no data.
7. **Invalid paging:** `pageNumber=0`, `pageSize=0`, `pageSize=51` → 400 `validation.failed` + field errors.
8. **Unknown patient:** same 404 shape as cross-doctor.
9. **Empty result set:** 200 with empty `items`, `totalPages` 0 (CONVENTIONS.md rule).
